# WinPlay1.2.0

WinPlay让Windows电脑成为无线CarPlay接收端，显示iPhone的CarPlay画面、播放声音，并用鼠标或触控板操作。支持本机移动热点与现有局域网两种无线方式，适合Windows笔记本、平板和桌面显示器。

本次更新加入多语言与“关于”页，整理连接、显示和音频设置，完善无线连接、窗口操作与更新管理，并改进音视频流畅度。

## 更新内容

### 应用设置与管理

- 主窗口调整为连接、显示、音频和关于四页，采用统一的分组卡片。语言、外观与关闭行为放在“连接→应用”，版本、更新、日志和认证文件集中到关于页。
- 新增跟随系统、简体中文、繁體中文和English四种应用语言，切换立即生效，设置界面、托盘和确认框同步切换。浅色、深色与跟随系统主题只影响WinPlay，CarPlay的语言与外观由iPhone决定。
- 支持检查GitHub正式发行版并打开对应的x64安装包下载入口。自动检查默认开启，每天最多检查一次；下载通过浏览器完成，安装由用户执行。
- 完善任务栏与托盘操作。主窗口和CarPlay窗口正常最小化到任务栏，可选择关闭主窗口后留在托盘继续接收；关闭CarPlay窗口时先确认断开，完整会话结束后自动关闭画面窗口并恢复“启动接收”。
- 支持打开和导出日志，保存与导出时过滤网络标识、个人路径、认证材料和配对密钥，方便反馈问题。

### 无线连接

- 本机移动热点与现有局域网分别保存配置，按所选模式检测网络接口。热点模式识别Windows实际用于共享的接口，并等待链路和地址就绪。
- 统一使用“读取当前网络和密码”：热点模式读取Windows移动热点设置，局域网模式读取当前Wi-Fi及对应的已保存密码。无法读取的字段显示具体原因并保留原输入，可继续手动填写。
- 完善局域网设备发现与连接等待，连接前刷新当前网络参数，区分网络连接超时与视频等待超时，减少沿用旧SSID、密码或接口造成的连接问题。

### 显示与流畅度

- 收到视频并完成首帧解码后再显示CarPlay窗口，等待连接时不弹出黑色画面窗口；停止后的旧视频数据不会重新打开窗口。
- 统一分辨率预设、自定义像素与请求像素设置。普通画面窗口按所选显示器的物理像素固定尺寸，保持视频比例；超出屏幕可用范围时提示修改，不静默缩小。
- 首次默认1280×720、60fps，帧率可选30/60/90/120fps。120fps启动失败后依次尝试90fps和60fps，实际输出取决于iPhone、网络与解码能力。
- 视频接收使用有界队列与TCP背压，减少数据积压及参考帧损坏；已解码画面只绘制最新一帧，改善快速滑动时的延迟。硬件解码持续停滞时，在限定的恢复流程内尝试软件解码。

### 音频与媒体

- 修正AAC丢包后的RTP时间戳映射，减少后续音频持续迟到和播放断续。保留真实音频缺口，不通过加速播放追赶，并隔离旧解码回调。
- 保留媒体与通话音量分别调节、输入/输出设备选择，支持Windows系统媒体控件同步播放信息和封面，回传播放/暂停、切歌及播放器允许的进度跳转。
- 歌词继续同步，封面独立去重并按需更新。歌词变化不会反复触发封面同步，新曲目的首张封面立即显示，同一首歌内连续变化的封面合并处理。

无线连接与音视频表现仍受设备、网络和输出设备影响，可在接收统计与音频运行统计中查看当前情况，遇到持续异常时导出日志反馈。

## 下载与安装

请在[GitHubReleases](https://github.com/Roylyl/WinPlay/releases)查看已发布的版本及附件。WinPlay1.2.0使用以下安装包：

| 安装包 | 适用系统 |
| --- | --- |
| `WinPlay-1.2.0-Setup-x64.exe` | Windows10/11x64 |

单个离线EXE内置运行时与Windows平台桥接，无需另外安装Node.js或开发工具。运行安装包，按向导完成安装并打开WinPlay。更新时先退出旧版，再运行新版安装包；已有设置、导入认证文件和配对数据保留。当前安装包未做发行代码签名，Windows可能显示安全提示。

### 开始连接

电脑需具备蓝牙与Wi-Fi能力，iPhone需支持CarPlay并开启Wi-Fi与蓝牙。无线网络需允许两端互访，Windows防火墙需允许WinPlay通信；使用热点模式时，先在Windows设置中开启移动热点。

本地构建包内置构建者提供的配套认证文件，也可在关于页导入有权使用的材料；本机导入文件优先。普通Apple开发者签名证书不能替代CarPlay配件认证，公开分发前需确认内置材料的授权。

1. 在Windows蓝牙设置中配对iPhone，回到WinPlay刷新列表并选择目标设备。
2. 选择“本机移动热点”或“现有局域网”。使用局域网时，让电脑与iPhone加入同一Wi-Fi；点击“读取当前网络和密码”，无法读取的部分按实际网络配置手动填写。
3. 在“关于→认证文件”确认配套文件已就绪。需要替换时，一次选中有权使用且匹配的`identity.pk8`与`certificate.p7b`导入，本机导入文件优先，最终认证由iPhone决定。
4. 点击“启动接收”，在iPhone上允许CarPlay。修改连接、显示或音频设备设置后，点击“应用并重新连接”。

本版本仅提供无线接收，不支持USB直连。停止接收不会关闭Windows移动热点。

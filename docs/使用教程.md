# WinPlay1.1.0使用教程

## 安装与认证

使用Windows10/11x64，双击桌面`WinPlay-1.1.0-Setup-x64.exe`完成安装。运行时和平台桥接已经内置，不需要安装开发工具。安装包尚未做发行代码签名。

本地安装包内置用户提供的认证文件。需要更换时，在“诊断→导入认证文件”选择有权使用的`identity.pk8`和匹配的`certificate.p7b`；本机导入文件优先。材料能否公开分发仍需授权确认，iPhone必须接受认证才能连接。

## 无线连接

1. 开启两端蓝牙，在Windows蓝牙设置中配对iPhone，回到WinPlay刷新并选择iPhone。
2. 本机移动热点：点击“打开移动热点”，在Windows设置中开启热点，让iPhone加入；填写热点实际名称、密码与信道。
3. 现有局域网：两端加入同一Wi-Fi，填写路由器名称、共享密码与实际信道。可以读取当前网络和Windows保存的密码；读取失败时手动填写。可选BSSID应填写路由器地址。
4. 确认自动推荐的网络接口。热点使用活动共享接口或Wi-FiDirect虚拟接口，局域网使用物理网络接口。热点未开启时先开启再刷新；有效的同模式手动选择会保留。两个模式的设置分别保存。
5. 点击“启动接收”，在iPhone上允许CarPlay。CarPlay窗口立即打开，等待视频时为黑色；修改配置后点击“应用并重新连接”。

防火墙需允许WinPlay与iPhone互访。TCP17000、动态媒体端口和UDP5353用于接收与Bonjour发现。企业认证、网页登录和客户端隔离网络可能无法连接。停止接收不会关闭Windows热点。

## 画面与输入

“显示→视频分辨率”包含屏幕原生像素、1280×720、1920×1080、2560×1440和自定义，首次默认1280×720、60fps。自定义时显示宽高输入，请求像素随选择更新；配置应用前不会自动重新连接。

画面区域按物理像素设置，不受Windows缩放放大。普通窗口可以拖动标题栏移动，禁止调整大小；视频保持比例。原生像素或屏幕最大分辨率采用全屏窗口化，Esc和Win+D可最小化。超过所选屏幕可用区域会明确报错。

鼠标点击、拖动和触控板上下/左右滚动可操作画面。帧率请求可选30/60/90/120，120失败回退90，再失败回退60；实际收到和实际解码帧率独立计数，不等于屏幕刷新率。

## 音频、退出与诊断

音量和播放开关实时生效；输入/输出设备默认跟随系统，切换设备后应用并重新连接。麦克风使用需要系统权限。系统媒体控件接收可获取的音乐信息，并回传播放、切歌及设备支持的进度跳转。标题歌词变化不会清除同曲封面。

首次关闭主窗口时选择退出或最小化，可勾选“不再提示”，之后在“显示→窗口行为”修改。最小化保持接收；主动停止、关闭CarPlay窗口或会话断开后关闭画面，主界面恢复“启动接收”。

诊断页支持导入认证、打开认证目录、打开日志和导出筛选记录。用户数据位于`%APPDATA%\WinPlay\data`，使用WindowsDPAPI保护，卸载默认保留。不要公开该目录。

# WinPlay1.2.0使用教程

## 安装与认证

使用Windows10/11x64，双击桌面`WinPlay-1.2.0-Setup-x64.exe`完成安装。运行时和平台桥接已经内置，不需要安装开发工具。安装包尚未做发行代码签名。

本地安装包内置用户提供的认证文件。需要更换时，在“关于→认证文件→导入认证文件”一次选中有权使用的`identity.pk8`和匹配的`certificate.p7b`；本机导入文件优先。材料能否公开分发仍需授权确认，iPhone必须接受认证才能连接。

## 无线连接

1. 开启两端蓝牙，在Windows蓝牙设置中配对iPhone，回到WinPlay刷新并选择iPhone。
2. 本机移动热点：点击“打开移动热点”，在Windows设置中开启热点，再点击“读取当前网络和密码”。名称和密码来自系统热点设置，信道0表示自动发现；启动时会刷新交接配置，iPhone仍未加入时可手动连接该热点。
3. 现有局域网：两端加入同一Wi-Fi，点击“读取当前网络和密码”，读取名称、实际信道和同一网卡对应的已保存密码；读取失败的字段手动填写。可选BSSID应填写路由器地址。
4. 网络接口默认“自动检测”，也可手动选择。热点按Windows实际私有共享接口、地址和链路状态判断；局域网选择已连接的物理网卡。热点未开启时先开启，WinPlay会等待接口就绪；两个模式的设置分别保存。
5. 点击“启动接收”，在iPhone上允许CarPlay。收到视频并完成首帧解码后自动显示CarPlay窗口；等待连接时留在主窗口查看状态。修改配置后点击“应用并重新连接”。

防火墙需允许WinPlay与iPhone互访。TCP17000、动态媒体端口和UDP5353用于接收与Bonjour发现。企业认证、网页登录和客户端隔离网络可能无法连接。停止接收不会关闭Windows热点。

## 画面与输入

“显示→视频分辨率”包含屏幕原生像素、1280×720、1920×1080、2560×1440和自定义，首次默认1280×720、60fps。自定义时显示宽高输入，请求像素随选择更新；配置应用前不会自动重新连接。

画面区域按物理像素设置，不受Windows缩放放大。普通窗口可以拖动标题栏移动，禁止调整大小；视频保持比例。原生像素或屏幕最大分辨率采用全屏窗口化，Esc和Win+D可最小化。超过所选屏幕可用区域会明确报错。

鼠标点击、拖动和触控板上下/左右滚动可操作画面。帧率请求可选30/60/90/120，120失败回退90，再失败回退60；实际收到和实际解码帧率独立计数，不等于屏幕刷新率。

## 音频与窗口

音量和播放开关实时生效；输入/输出设备默认跟随系统，切换设备后应用并重新连接。麦克风使用需要系统权限。系统媒体控件接收可获取的音乐信息，并回传播放、切歌及设备支持的进度跳转。标题歌词变化不会清除同曲封面。

音乐沿用AAC协商方式，播放前保留协商缓冲，导航和通话使用较短缓冲。歌词正常同步，相同封面不重复发送到Windows媒体控件，同曲连续封面变化最多每5秒更新一次。

两个窗口的“－”均正常最小化到Windows任务栏，保留任务栏图标和接收。首次关闭主窗口时选择退出或最小化到托盘，可勾选“不再提示”，之后在“连接→应用”修改。关闭CarPlay窗口会先询问是否断开，取消后保持连接，确认后停止接收。

主动停止或完整会话断开后关闭画面，主界面恢复“启动接收”，保留当前页面。托盘右键菜单可启动、停止接收，显示主窗口或画面，退出应用。Esc将CarPlay窗口最小化到任务栏，保留图标与连接，可点击任务栏图标恢复。

## 语言、更新与日志

在“连接→应用”选择简体中文、繁体中文、English或跟随系统，切换立即生效，也可调整WinPlay自身外观。

“关于→软件更新”默认开启后台自动检查，每天最多自动检查一次；可手动检查、查看发行说明或下载对应x64安装包。下载安装由用户决定。

关于页的日志与认证内容默认折叠。打开“最近日志”可查看、复制状态；出现音频异常时导出日志，并说明输出设备、无线模式、现象和大致时间。保存、打开和导出日志都会过滤敏感信息。用户数据位于`%APPDATA%\WinPlay\data`，敏感数据使用WindowsDPAPI保护，卸载默认保留。不要公开该目录。

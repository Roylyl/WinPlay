# WinPlay1.2.4版本说明

WinPlay是Windows无线CarPlay接收端，支持本机移动热点与现有局域网连接。

## 运行要求

- Windows10/11x64，电脑需要可用的蓝牙适配器。
- 本机移动热点模式需要支持Windows移动热点的Wi-Fi网卡。
- 局域网模式支持电脑通过Wi-Fi或以太网接入网络，iPhone通过Wi-Fi接入，两端需要可互访。
- 使用前完成蓝牙配对，并确认认证材料满足使用前提。

## 安装与连接

安装包为`WinPlay-1.2.4-Setup-x64.exe`，单个离线EXE内置运行组件。首次安装默认1280×720、60fps，普通画面窗口按屏幕可用空间适配，并允许拖动边框等比例缩放。

“显示→视频分辨率”提供默认关闭的“严格按屏幕物理像素显示”。成功读取所选显示器的真实像素尺寸后，才允许开启严格显示或选择屏幕原生像素。严格显示按1∶1物理像素显示；关闭时自动适配窗口大小，不改变向iPhone请求的视频分辨率。屏幕原生像素采用全屏窗口化显示。

检测中或读取失败时，普通窗口仍可使用并等比例缩放。点击“显示位置”旁的“刷新”重新检测，读取成功后可手动开启严格显示或选择屏幕原生像素。

升级前退出旧版，再运行新版安装包，已有设置、导入认证文件和配对数据保留。

局域网模式填写iPhone所连接Wi-Fi的SSID、密码与实际信道。电脑仅使用以太网时，需要手动填写这些参数；启动接收后按页面提示让iPhone加入指定Wi-Fi，再等待CarPlay画面。

遇到问题可在“关于”页导出诊断JSON。完整使用方法见[README](../README.md)，版本发布与更新内容见[GitHubReleases](https://github.com/Roylyl/WinPlay/releases)。

“无线连接被动断开时自动重连”默认关闭，可在连接页开启。已建立的连接被动断开后，按5、10、20、30、60秒的等待间隔回连，之后保持60秒间隔；每次只执行一个连接尝试。主动停止接收、确认断开或退出程序会取消回连。重新收到视频后恢复正常状态，后续被动断开重新从5秒开始。

## 自动检查更新

自动检查更新默认开启：每次启动后检查一次，软件运行期间每隔两小时后台检查。最小化到任务栏或托盘时继续检查，后台定时检查不弹出对话框；关闭自动检查后不执行启动或定时检查。手动检查可随时执行。
